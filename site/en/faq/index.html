Frequently asked questions about Tlaku

Tlaku is free, open source software for laser engravers and cutters, and a LightBurn alternative. These are the most common questions, with answers you can check in the repository.

Questions

Is Tlaku free?

Yes. Tlaku is free software under the MIT license: you can use, copy and modify it without paying, and its code is open on GitHub. There is no paid version and no locked features: donating is optional and unlocks nothing, the program is the same with or without a donation.

Which laser machines does it support?

Most diode lasers with a GRBL controller over USB (GRBL 1.1 with M4 and GRBL-M3), plus grblHAL, FluidNC, Marlin and Smoothie. There is a catalog of models from brands such as Creality, Sculpfun, Atomstack, Ortur, xTool, Longer, Neje and Two Trees. Ruida (CO2), K40 with an M2 Nano board and fiber galvo are experimental.

Important: so far it has been tested on only one real machine, a Creality Falcon2 Pro 22 W (without high-power cutting). The others were tested with emulators and virtual machines. See the machine table and its status and the Tlaku for the Creality Falcon2 page.

Does it open LightBurn files?

Yes: it opens .lbrn and .lbrn2 projects with their layers and settings (File > Import Design… or by dragging the file in), and it imports .lbdev machine profiles from Devices. It does not read .lbvendor or .lbzip bundles (a .lbzip is a zip: extract the .lbdev and use that).

Whatever has no equivalent appears in a notice, and some conversions were inferred from public documentation: check every layer in the preview before cutting. More in Free open-source LightBurn alternative. LightBurn is a trademark of its owner; Tlaku is not affiliated with it.

Does it work with a Ruida controller or a K40?

Ruida (CO2): experimental support over the network (UDP): connect, send (by default it stores the job on the controller and does not start it), pause, stop and framing. Tested only against an emulator, and it does not write the controller's settings.

K40 with an M2 Nano board: experimental support over direct USB, tested only against a simulated board. Power is set with the machine's knob, not by software. A K40 whose board was swapped for GRBL-LPC or Smoothie may work as a GRBL machine.

Neither has been tested on real hardware: treat them as a test and tell us how it goes.

Does it work without internet?

Yes. Designing, preparing a job and sending it to the machine does not need internet: the machine connects over USB or your local network. The internet is used for only two optional things:

  • Opening the community settings library, which downloads a catalog from the project's site (offline it shows the last saved copy).
  • Checking for updates (Help menu).

Tlaku sends nothing on its own: error and test reports open pre-filled in your browser and you decide whether to post them. To install it you do need to download the installer once.

Does it update itself?

It tells you and updates with your permission, not behind your back. In Help > Check for Updates…, if there is a new version you see its number and notes and choose Download and install or Not now. The check at startup is off by default (turn it on in Preferences > General), it never installs while a job is running, and the download is verified with the project's signature.

On Linux only the AppImage updates from the app; the .deb is reinstalled by hand, and with Flatpak updates come from Flatpak.

Why does the “unidentified developer” warning appear and how do I open it?

Because the installers are still unsigned: Apple and Microsoft code-signing certificates are paid and must be renewed, and the project does not have them yet. The system warns about any unsigned program. Download Tlaku only from the repository's releases page; the code is open and you can inspect it.

  • macOS: right-click Tlaku, Open; or in System Settings > Privacy & Security, Open Anyway. If it says the app is damaged, run in Terminal: xattr -dr com.apple.quarantine /Applications/Tlaku.app
  • Windows (SmartScreen): More info and then Run anyway.
  • Linux: no warnings. To use the laser's serial port, add your user to the dialout group (sudo usermod -aG dialout "$USER") and log in again.

Which operating systems does it run on?

Windows 10 or later (.exe or .msi installer), macOS 11 or later (one universal .dmg for Apple Silicon and Intel) and Linux (.deb and .AppImage). Linux ARM64 (64-bit Raspberry Pi 4 and 5) and Flatpak are experimental and have not been tried on a real device. The app and the manual are in Spanish and English.

Is it ready for production use?

Not yet: it is a beta. Engraving lines, fills and images was tested on a real Creality Falcon2 Pro 22 W, but high-power cutting has not been tested on any machine. Treat every job as a test: low power, scrap material and your hand near the emergency stop. If you depend on another program, keep it as a plan B.

How can I help?

  • Try Tlaku on your machine and tell us how it went, even if everything worked: test report and validation list (in Spanish).
  • Share your material settings (they join the library as unverified community data, CC0): form.
  • Ask for your controller if it is missing: support request. And report bugs with the bug form.
  • Buy a coffee on Ko-fi: it is optional and pays for test machines and development time. Ko-fi
  • Star the repository and tell anyone who owns a laser: it helps more people find it.
  • Code, documentation and translations: read CONTRIBUTING.md.

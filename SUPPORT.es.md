# Cómo obtener ayuda

[English](SUPPORT.md) · Español

## Preguntas e ideas: Discusiones

Para «¿cómo hago…?», «¿funciona con mi máquina?» o «¿y si…?», usa las
[Discusiones](https://github.com/jahziel1/tlaku/discussions). Busca antes: puede que tu pregunta ya tenga
respuesta.

## Lee primero el manual

- [Manual de usuario (Español)](docs/manual/00-indice.md): primeros pasos, conectar una máquina, enviar con
  seguridad, materiales y [solución de problemas](docs/manual/15-solucion-de-problemas.md).
- [User manual (English)](docs/manual/en/00-indice.md).
- El manual también está dentro de la app: Ayuda > Manual de usuario (con buscador).

## Reportes

Usa el formulario que corresponda en [Issues](https://github.com/jahziel1/tlaku/issues/new/choose):

| Quieres… | Formulario |
|---|---|
| Reportar algo que no funciona | [Reportar un error](https://github.com/jahziel1/tlaku/issues/new?template=bug_report.yml) |
| Contarnos cómo funcionó Tlaku en tu máquina real | [Reporte de prueba en una máquina real](https://github.com/jahziel1/tlaku/issues/new?template=machine_report.yml) |
| Compartir ajustes de material que te funcionaron | [Compartir ajustes de material](https://github.com/jahziel1/tlaku/issues/new?template=material_settings.yml) |
| Pedir una controladora nueva | [Soporte para una controladora nueva](https://github.com/jahziel1/tlaku/issues/new?template=new_controller.yml) |
| Proponer una función | [Proponer una función](https://github.com/jahziel1/tlaku/issues/new?template=feature_request.yml) |

El menú Ayuda de la app puede abrir estos formularios ya llenos con tu versión, sistema y máquina. No se
envía nada sin que lo revises.

## Problemas de seguridad

**No uses issues ni discusiones públicas** para vulnerabilidades ni para nada que pueda encender el láser
donde no debe, no detenerlo o mover la máquina sin querer. Repórtalo en privado: ver
[SECURITY.es.md](SECURITY.es.md).

## Sobre este proyecto

Tlaku lo hacen voluntarios y no tiene soporte comercial. Tlaku solo se ha probado con emuladores: trata cada
trabajo como una prueba y ten el paro de emergencia al alcance. El proyecto sigue su
[Código de conducta](CODE_OF_CONDUCT.es.md).
